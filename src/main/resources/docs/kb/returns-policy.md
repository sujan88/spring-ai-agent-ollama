# Returns and Refunds Policy

## Return window

Most items can be returned within 30 days of delivery. The return window starts on the delivery date shown on the order, not the order date. Clearance items cannot be returned. Opened software and gift cards cannot be returned.

## Refund method

Refunds go back to the original payment method. Card refunds appear within 5 to 10 business days after the warehouse receives the item. Orders paid with store credit are refunded as store credit.

## Partial refunds

A partial refund is issued when an item comes back damaged, used or missing parts. Support agents can approve a partial refund only when AllowPartialRefund = true is set on the order.

## Return shipping cost

Return shipping is free for defective or wrong items. For any other reason a flat return label fee of 6 dollars is deducted from the refund.

## Exchanges

We do not process direct exchanges. Return the item for a refund and place a new order for the size or colour you want.
